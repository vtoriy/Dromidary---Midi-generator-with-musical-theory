# Распределение функций по вводу

## Физические кнопки

- **16 нотных кнопок** — ввод нот (значение зависит от текущей октавы + транспозиции).
- **6 функциональных кнопок**: Play, Record, Shift, Rest, Octave Down, Octave Up.

Кнопки читаются через каскад 2× 74HC165 (см. `01-hardware.md` про битовую карту и
известный баг с перепутанной разводкой D4–D7 на втором чипе).

## Джойстик KY-023

Аналоговый X/Y + кнопка. Используется для:
1. Навигации по меню (короткий тап влево/вправо = ±1, удержание = pop/переключение
   screen_mode — см. `04-menu-navigation.md`).
2. Радиального выбора типа аккорда / стиля арпеджио (8 секторов, см. ниже).
3. Ввода значений параметров (короткий тап = ±1 шаг, Shift + тап = прыжок к
   крайнему значению).
4. В перспективе — источник для длинных диапазонов через удержание (авторепит),
   пока не добавлен энкодер.

### Ввод значений — детали (зафиксировано с заказчиком)

- Обычное изменение значения — джойстик влево/вправо (±1 шаг).
- Альтернативный способ для быстрого набора — **нотные клавиши с зажатой Shift**
  (числовой ввод через ноты). Соответствие: 1-я нотная клавиша = цифра 0,
  2-я → 1, ..., 10-я → 9. Клавиши 11–16 не задействованы в числовом вводе.
- **Крайние значения** (min/max) — Shift + джойстик влево/вправо.
- Удержание джойстика в **любом из 4 направлений** (UP/DOWN/LEFT/RIGHT, реализовано
  02.08.2026) — авто-повтор с ускорением: навигация вниз/вверх по пунктам
  (submenu) и строкам, быстрый ввод значений влево/вправо. В радиальном
  селекторе авто-повтор не действует (выбор зоны разовым наклоном).

  ```python
  # Ступенчатая кривая авто-повтора (как в code.py: _joy_repeat_interval)
  REPEAT_START_MS = 350       # задержка перед началом повтора
  REPEAT_STAGES = [
      (1000, 150),   # 0–1 с: каждые 150 мс
      (2000, 80),    # 1–2 с: каждые 80 мс
      (3000, 40),    # 2–3 с: каждые 40 мс
      (float('inf'), 25),  # 3+ с: каждые 25 мс (максимум)
  ]
  # При отпускании джойстика таймер сбрасывается.
  ```

## Радиальный селектор джойстика (общий виджет для Key, аккордов и арпеджио)

Все три параметра (Key, CType, AStyle) используют один и тот же механизм:
360° делятся на **8 секторов по 45°**, offset +22.5°:

```python
import math

def joystick_to_zone(dx, dy, deadzone=DEADZONE_THRESHOLD):
    magnitude = math.hypot(dx, dy)
    if magnitude < deadzone:
        return None
    angle_deg = math.degrees(math.atan2(dy, dx)) % 360
    zone = int(((angle_deg + 22.5) // 45)) % 8
    return zone
```

### Поведение (зафиксировано 01.08.2026)

Радиальный селектор — **только в QUICK** (быстрая смена). Радиальный параметр
требует **клика** джойстика для входа в edit mode:
- клик → edit mode; движение джойстика в любом направлении выбирает зону;
- повторный клик выходит из edit mode (курсор не сбрасывается);
- **без клика** LEFT/RIGHT на радиальной ячейке только перемещает фокус — чтобы
  не мешать навигации по экрану QUICK.

Линейные ячейки QUICK (Key, Dens, Shape) — тоже клик-цикл: клик → влево/вправо
меняет значение → клик. В **DETAIL/MAIN** радиального управления нет: все пункты
(option/slider/toggle) редактируются влево/вправо **сразу, без клика**; переход
на другой пункт автоматически принимает значение.

Радиальные ячейки QUICK: **Scale, CType, AStyle, Strum** (Strum — задержка
струма, зоны Off/5/10/15/20/25/30/35 мс). Параметр **Key** (12 нот) — линейный:
клик → влево/вправо меняет ноту → клик; в строке показывается только выбранная
нота, без предикта соседних.

### Раскладка зон

| Zone | Направление | Scale (лад) | CType (аккорд) | AStyle (арпеджио) |
|---|---|---|---|---|
| 0 | Вверх | **Off** (фильтр выкл) | **Off** (аккорд выкл) | **Off** (арп выкл) |
| 1 | Вверх-вправо | Major | Maj | Up |
| 2 | Вправо | Minor | Min | Down |
| 3 | Вниз-вправо | Dorian | Maj7 | Up-Down |
| 4 | Вниз | Phrygian | Min7 | Down-Up |
| 5 | Вниз-влево | Lydian | Dom7 | As played |
| 6 | Влево | Mixolydian | Sus4 | Random |
| 7 | Вверх-влево | Blues | Power | Converge/Diverge |

Выбор Scale≠Off автоматически включает Key Filter, CType≠Off — Chord,
AStyle≠Off — Arp (отдельных свитчей в Quick Menu нет).

### Отображение фокуса Quick (01.08.2026)

Подчёркивание/инверсия заливкой убраны. Фокусная ячейка — в квадратных
скобках (`[C]`, `[Off]`, `[PRM]`); при изменении значения в edit mode к
скобке добавляется `!` (`[C#]!`), исчезающая после подтверждения/отмены/сброса.
Названия строк по левому краю (`CHD` вместо `Chord`, `ADR` вместо `ADSR`),
`>` в строках Quick убран. В Param-подменю изменённые значения помечаются `+-`.

**Сброс значения — Rest + кнопка джойстика во всех видах меню.** Сброс
срабатывает по **фронту** нажатия Rest (Rest зажат не более чем за 800 мс до
клика). В QUICK сбрасывает ячейку к значению на момент входа в edit mode; в
DETAIL/MAIN — пункт к снимку на момент его фокусировки. Дополнительно в
DETAIL/MAIN работает **двойной клик** (~350 мс) как альтернативный сброс того же
пункта. Благодаря фронтовому
детекту неиспользуемые биты 4–5 (постоянно читаются 0) не блокируют одинарный клик:
если фронт Rest
не зарегистрирован, клик всегда идёт в `press_short()` (вход в edit / в PRM).

**Диагностика распиновки функц. кнопок** — при любом изменении chip3 в консоль
выводится
`FUNC chip3=0x.. P=.. REC=.. OCTDN=.. OCTUP=.. SHIFT=.. REST=..` (1 = кнопка нажата).

**Распиновка chip3 зафиксирована (02.08.2026 по логу FUNC, 1 = нажато):** Play=bit0,
**Rest=bit1**, **Rec=bit2**, **Shift=bit3**, **OctUp=bit6** («+»), **OctDown=bit7**
(«−»); биты 4–5 не подключены (всегда 0). Соответствие подтверждено сверкой лога
с физическими нажатиями.

(Полный расширенный список типов аккордов из `03-data-structures.md` доступен
только через MAIN и DETAIL (полные списки); радиальный селектор QUICK принципиально
ограничен 8 зонами, по ТЗ.)

## Функционал кнопки Rest

Кнопка Rest, помимо базовой "пауза на шаге при записи", получает расширенный набор
функций (аналог принятых решений в грув-боксах типа Elektron/Korg — предложено и
согласовано с заказчиком):

| Комбинация | Функция |
|---|---|
| Rest (тап), realtime record | Вставить явную паузу (rest) на текущем шаге |
| Rest (тап), step-edit на выбранном шаге | Стереть ноту(ы) этого шага |
| Shift + Rest (тап) | Обнулить всю дорожку/паттерн |
| Rest + note-key (удерживая обе) | **Tie** — продлить предыдущую ноту через текущий шаг без нового Note On (компаньон к Legato при пошаговом вводе) |
| Удержание Rest во время playback (вне записи/редактирования) | **Live-mute** — временно глушит MIDI-вывод, пока кнопка зажата; отпустил — играет дальше (перформанс-функция) |

## Октавы и транспонирование

- **Octave Down / Octave Up** — сдвигают базовую октаву нотных клавиш
  (`runtime.base_octave`, по умолчанию 4). Хранится в runtime, отображается в
  статус-баре как `o{октава}`. Не влияет на уже записанные в паттерн ноты, только
  на последующий живой ввод. (Не путать с `pattern.transpose.octaves`.)
- Отдельная функция транспонирования (п.6 ТЗ) — в полутонах и в октавах,
  `pattern.transpose`. Применяется к сырой ноте **до** Key Filter (см.
  `02-midi-chain.md`), чтобы транспонированная нота тоже корректно снималась в
  тональность. Влияет и на живой ввод, и на записанные ноты при воспроизведении.

## Play / Record / Shift

- **Play** — старт/стоп воспроизведения активного паттерна. Дополнительно шлёт по
  MIDI **Start** (0xFA) при старте и **Stop** (0xFC) при остановке (синхронизация
  транспорта Ableton).
- **Record** — вход в запись (realtime или step-edit, в зависимости от того,
  остановлено ли воспроизведение — см. `00-overview.md` про запись/перезапись,
  overdub по умолчанию, Shift+Rec = полная перезапись/обнуление). Дополнительно
  шлёт по MIDI **Continue** (0xFB) — условный сигнал записи для Ableton.
- **Shift** — модификатор для всех вышеперечисленных комбинаций (крайние значения
  параметров, обнуление дорожки, потенциально числовой ввод через нотные клавиши).

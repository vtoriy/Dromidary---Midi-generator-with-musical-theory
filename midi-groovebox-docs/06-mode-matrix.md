# Матрица доступности функций по режимам работы

Устройство работает в одном из режимов (`runtime.mode`). В текущем C++-релизе
(alpha) через меню доступны **два** режима — заголовок (статус-бар) в Quick
служит их переключателем:
**MIDI-клавиатура (KB)** и **Случайная нота (RND)**. Остальные значения enum
(`Pattern`, `RandomPattern`, `MidiFilter`) зарезервированы на будущее — через UI
не включаются (см. `07-roadmap-open-questions.md`).

| Режим | Live-игра | Key Filter | Аккорды | Арпеджио | Случ. генерация | Запись в паттерн |
|---|---|---|---|---|---|---|
| **MIDI-клавиатура (KB)** | да | да | да | да | нет | нет (в alpha) |
| **Случайная нота (RND)** | да (клавиши задают якорь) | да | да | нет (отд. таймер) | да (непрерывный поток) | нет |

## Пояснения к режимам

### MIDI-клавиатура (KB)

Прямая игра с нотных клавиш. Конвейер: transpose → key filter → chord builder →
secondary filter → (арпеджио, если включён). Полифонический арпеджио по всем
зажатым клавишам; при выключенном арпеджио одновременные клавиши играют
полифонично. Latch (залипание) работает и с арпеджио (моно-замена при latch ON),
и без него (простое залипание ноты).

Кнопка **Play** действует как транспорт арпеджио: одно нажатие гасит всё звучащее
(арп/клавиши), пока на входе что-то активно; повтор без звука ничего не делает.
Начало арпеджио возобновляется очередной нажатой клавишей.

### Случайная нота (RND)

Непрерывная генерация случайных нот. Каждая нажатая клавиша **задаёт якорную
ноту** генератора (первое нажатие или Play запускает цикл; повторное Play
останавливает). Ноты выбираются из диапазона PITCH (дефолт C1–B1), фильтруются в
текущую тональность; длина — из диапазона LEN (дефолт — фиксированная 1/8);
**Len Chain On (дефолт)** — следующая нота стартует ровно в момент окончания
гейта предыдущей, Off — шаги по сетке ARP Rate с капом длины интервалом. REP
задаёт шанс повтора якорной ноты. Триоли в списке длин включаются в Timing →
Triplets (дефолт Off). Аккорды в RND не используются (в отличие от
Python-прототипа). Dens/Shape зарезервированы и на генерацию в alpha не влияют.

### Зарезервированные режимы (не в UI в alpha)

- **Pattern** — просмотр/воспроизведение записанного паттерна (паттерн-секвенсор
  не реализован).
- **RandomPattern** — авто-генерация целого паттерна (требует секвенсора).
- **MidiFilter** — обработка MIDI IN через конвейер (нужен MIDI IN по UART).

Нотные клавиши в зарезервированных режимах игнорируются (`note_on` возвращает
сразу).

## Что влияет на генерацию случайной ноты

| Параметр | Где | Эффект в RND |
|---|---|---|
| Key Filter (Root/Scale/Snap) | Quick: Key/Scale; Full: Key / Scale | фильтр сгенерированной ноты в лад |
| PITCH (NT_RNG) | Quick: Rand → PITCH; Full: Randomize → Note Range | диапазон высоты случайной ноты (дефолт C1–B1) |
| LEN (LEN_RNG) | Quick: Rand → LEN; Full: Randomize → Len Range | диапазон длины ноты (`128…2`, `'1…'4`); min==max — фиксированная длина; триоли подключаются в Timing → Triplets |
| Len Chain | Full: Randomize → Len Chain | On (дефолт): цепочка длин — onset в момент окончания гейта, ARP Rate не влияет; Off: сетка ARP Rate, длина капится интервалом |
| REP | Quick: Rand → REP | шанс повтора якорной ноты, 0..90 % шаг 10 % |
| Dens (Density) | Quick: Other; Full: Randomize → Density | зарезервирован (в alpha поток непрерывный), шаг редактирования 10 % |
| Shape | Quick: Other; Full: Randomize → Shape | зарезервирован |
| BPM / Arp Rate | Full: Timing → BPM; Arpeggiator → Rate | темп следования нот (при Len Chain Off) |

> В alpha RandomNote использует только часть `random_cfg` (диапазон + длины +
> повтор + якорь + фильтр + темп); velocity и полноценная генерация паттернов
> отложены — см. `03-data-structures.md` и `07-roadmap-open-questions.md`.

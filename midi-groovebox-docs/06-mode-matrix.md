# Матрица доступности функций по режимам работы

Устройство работает в одном из пяти режимов (`runtime.mode`), доступный
функционал зависит от режима:

| Режим | Запись в паттерн/воспр. | Редакт. паттерна | Аккорды | ADSR | Квантизация | Triole | Swing/Groove | Humanize | Legato | Арпеджио | Случ. генерация | Параметры случайности |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| **MIDI-клавиатура** | да | нет | да | да | нет | нет | нет | нет | нет | **да** | нет | нет |
| **Паттерн** | нет | да | нет | да | да | да | да | да | да | нет | нет | нет |
| **Случайный паттерн** | да | нет | нет | да | да | да | да | да | да | нет | да | да |
| **Случайная нота** | да | нет | да | да | да | да | да | да | да | нет | да | да |
| **MIDI-фильтр** | да | нет | да | да | да | да | да | да | да | **да** | нет | нет |

## Пояснения к режимам

- **MIDI-клавиатура** — прямая игра с нотных клавиш, с фильтрацией по тональности
  и аккордами, без записи в паттерн-редактор (только realtime запись в память,
  без пошагового редактирования — соответствует "нет" в колонке "Редакт. паттерна").
  При recording=On запись идёт на текущий шаг паттерна.
- **Паттерн** — режим просмотра/редактирования уже записанного паттерна: без
  живого ввода нот (запись в этом режиме не идёт), но доступно полное
  редактирование (шаги, длины, инверсия, реверс, квантизация постфактум и т.д. —
  см. `00-overview.md`/задачи по step-edit). Нотные клавиши игнорируются
  (ModeEngine блокирует).
- **Случайный паттерн** — при входе генерируется целиком набор нот согласно
  `random_cfg`, паттерн зациклен и воспроизводится на повторе (секвенсор запущен);
  доступна вся система параметров случайности. Нотные клавиши игнорируются.
- **Случайная нота** — при каждом нажатии нотной клавиши генерируется случайная
  нота (не зацикленный заранее паттерн, а поток), поддерживает аккорды (в отличие
  от случайного паттерна) и параметры случайности (без "формы/стиля" — см. ниже).
- **MIDI-фильтр** — входящий MIDI IN трафик проходит через тот же конвейер
  (Key Filter → Chord → тайминг-эффекты). Сейчас ноты берутся с физических клавиш
  (как в midi_keyboard); при добавлении MIDI IN будет обрабатывать внешний поток.
  Арпеджиатор доступен (см. строку таблицы).

## Арпеджиатор

Арпеджиатор доступен в режимах **MIDI-клавиатура** и **MIDI-фильтр** (решение
зафиксировано, см. `07-roadmap-open-questions.md`). В режимах паттерна, случайного
паттерна и случайной ноты арпеджиатор не используется.

## Применимость параметров случайности к режимам

| Параметр | Случайный паттерн | Случайная нота |
|---|---|---|
| Длина ноты (от/до, кратно шагам или мс) | да | да |
| Диапазон нот (от/до) | да | да |
| Плотность / вероятность | да — плотность (доля пустых шагов) | да — вероятность генерации следующей ноты |
| Форма/стиль (восходящий/нисходящий/арка/др.) | да | **нет** (в потоке одиночных нот "форма" неприменима так же, как к целому паттерну) |
| Velocity (off / от-до / дельта) | да | да |

### Параметры диапазона нот — детали

- **Упрощённый режим**: выбор "близко/средне/далеко" относительно предыдущей
  ноты — близко = ±5 полутонов, средне = ±12 полутонов (дефолт), далеко = ±24
  полутона.
- **Подробный режим**: ручное указание диапазона от/до с конкретной нотой и
  октавой.

### Velocity-режимы (напоминание — хранится в структуре данных, не используется как
"динамика нажатия" в железе, см. `01-hardware.md`, физические кнопки on/off без
velocity-сенсора; это поле нужно для корректной генерации MIDI Note On с валидным
значением velocity, а также заготовка на случай будущего добавления velocity-чувствительного
ввода):

- **Off** — фиксированное значение 100 из 127.
- **От/до** — случайное значение в заданном пользователем диапазоне.
- **Дельта к текущему** — velocity текущей ноты + случайное значение в пределах
  заданной пользователем "дельты" (например velocity=100, дельта=10 → итоговое
  значение в диапазоне 100–110).

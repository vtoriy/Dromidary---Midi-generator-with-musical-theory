# MIDI Groovebox / Sequencer на Raspberry Pi Pico (RP2040) — обзор проекта

## Что это

Аппаратный **MIDI-контроллер / секвенсор / грувбокс** на базе Raspberry Pi Pico
(RP2040). Прошивка — **C++17 (Pico SDK 1.5.x)** в каталоге
[`firmware-cpp-alpha/`](../firmware-cpp-alpha/README.md) (ранее проект был на
Adafruit CircuitPython 10.0.3; Python-ветка удалена при переводе на C++).

Устройство **не содержит звукового движка** — это чистый **MIDI-генератор и
процессор**: принимает ввод с физических кнопок и джойстика, обрабатывает его
через конвейер (тональность → аккорды → арпеджио) и отправляет MIDI-события по
**USB MIDI**. В перспективе — аппаратный UART MIDI DIN.

## Ключевые функциональные блоки

1. **Фильтрация нот по тональности** (key filter) — 16 ладов, режимы обработки
   «неправильной» ноты: подъём (Snap Up), опускание (Snap Down) либо mute.
2. **Генератор аккордов** — 26 типов (трезвучия, септаккорды, sus, альтерации,
   quartal/quintal, cluster, power) с вторичной фильтрацией структуры по
   тональности.
3. **Арпеджиатор** — 8 стилей (Up, Down, Up-Down, Down-Up, As Played, Random,
   Converge/Diverge, Off), частота в длительностях нот (1/64–1/1) или в мс,
   диапазон в полутонах, длина цикла, **latch** (залипание/удержание).
4. **Живая игра (MIDI-клавиатура)** — полифонический арпеджио по всем зажатым
   клавишам; одновременные клавиши без арпеджио играют полифонично.
5. **Случайная нота (RandomNote)** — непрерывная генерация случайных нот вокруг
   якорной октавы, фильтрация в текущую тональность, темп — по частоте
   арпеджио.
6. **Транспонирование** — полутоны и октавы (до Key Filter), базовая октава
   клавиатуры (Oct Up/Oct Dn, 1–8).
7. **Меню** — Quick (быстрые ячейки), DETAIL (подменю из PRM), Full/MAIN (дерево),
   Animation (скринсейвер). Сброс значений Rest+клик, long-press для навигации.
8. **Системные настройки** — тайминги кликов (debounce/double/long),
   сохраняются во flash; экран **Test** для диагностики распиновки кнопок.
9. **MIDI CC-выход** — функциональные кнопки дублируются CC-сообщениями (для DAW).

## Аппаратная платформа

- **MCU**: Raspberry Pi Pico, RP2040.
- **Прошивка**: C++17, Pico SDK 1.5.x, TinyUSB (USB MIDI).
- **Дисплей**: монохромный OLED SH1106, I2C, 132×64 px.
- **Ввод нот**: 16 нотных кнопок + 6 функциональных (Play, Rest, Record, Shift,
  Octave Down, Octave Up).
- **Кнопки читаются через каскад сдвиговых регистров 74HC165** (24 бита ввода:
  16 нот + 8 функциональных; биты 4–5 chip3 не подключены).
- **Джойстик**: KY-023 (аналоговый X/Y + кнопка).
- **MIDI**: сейчас — USB MIDI (TinyUSB, device class). В перспективе — аппаратный
  UART MIDI (TX для OUT, оптрон для IN — см. `01-hardware.md`).

## Принятые решения по проекту (зафиксировано с заказчиком)

| Вопрос | Решение |
|---|---|
| MIDI-транспорт | USB MIDI сейчас, UART DIN добавится позже |
| MIDI IN | Нужен, но не сейчас (после UART) |
| Velocity | Не используется — только Note On/Off (фикс. 100) |
| Точность тайминга | Детерминированный цикл ~1 мс; тайминги кликов настраиваются |
| Ввод точных значений | Джойстик влево/вправо ±1, удержание — авто-повтор, Shift+наклон — крайние значения |
| Хранение | Клик-настройки — во flash (последний сектор, CRC32); паттерны — только ОЗУ |
| Многодорожечность | Один активный паттерн одновременно (без многодорожечности) |
| Порядок обработки ноты | Транспонирование → Key Filter → Chord → Arp (см. `02-midi-chain.md`) |
| Аккорд + тональность | Фильтруется вся структура аккорда целиком (вторичный фильтр) |
| Радиальный селектор | Общий виджет для Scale/CType/AStyle/Strum: 8 секторов по 45° |
| Режимы | MIDI-клавиатура (KB) и случайная нота (RND) — переключаются ячейкой Mode в Quick |
| Сброс значения | Rest + клик джойстика; двойной клик — дополнительно в DETAIL/MAIN |
| Функц. кнопки → MIDI | CC 20–25 на MIDI-канале 16 (127/0) |
| Известный баг 74HC165 | Перепутаны провода в диапазоне D4–D7 — оставить как есть (программный remap не вносить) |

## Известный аппаратный баг

На втором 74HC165 (диапазон D4–D7 по битовой карте) перепутаны провода: кнопка
№13 физически подключена к линии D7 вместо D4. **Решение:** оставить как есть —
текущее подключение работает, физическое расположение кнопок настроено под
конкретную плату. Программный remap не вносить (см. `01-hardware.md`).

## Статус проекта (alpha, C++)

Реализовано и работает на железе:

- статическая типизированная модель состояния (C++17, без динамической памяти);
- чтение 24 бит через каскад 74HC165 с двойным опросом и дебаунсом;
- джойстик KY-023 (8 направлений, клик, long-press, авто-повтор);
- драйвер SH1106 (I2C, 5×7 шрифт, framebuffer + flush);
- Key Filter (16 ладов), Chord Builder (26 типов), полифонический Arpeggiator;
- MIDI-клавиатура + непрерывный RandomNote-режим;
- Quick/DETAIL/MAIN/Anim меню, сброс Rest+клик, System-настройки кликов;
- сохранение клик-настроек во flash (magic `DROM`, версия 1, CRC32);
- USB MIDI Note On/Off + CC-дубли функц. кнопок;
- live-применение timing-эффектов (swing/humanize/quantize/legato),
  Gate/ADSR (attack/release) и voicing Block/Strum/Roll;
- экран Test (диагностика распиновки, выход Shift+клик).

### Что не реализовано (сознательно отложено)
- Паттерн-секвенсор: запись/воспроизведение/редактирование паттернов
- Режимы Random Pattern / Pattern / MIDI Filter
- UART MIDI DIN (OUT и IN)
- MIDI Clock sync
- Сохранение паттернов на flash (есть только клик-настройки)
- Velocity-чувствительный ввод

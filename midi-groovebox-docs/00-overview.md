# MIDI Groovebox / Sequencer на Raspberry Pi Pico (RP2040) — обзор проекта

## Что это

Аппаратный MIDI-контроллер/секвенсор/грувбокс на базе Raspberry Pi Pico (RP2040),
прошивка на Adafruit CircuitPython 10.0.3. Устройство не содержит звукового движка —
это чистый MIDI-генератор/процессор: принимает ввод с физических кнопок, джойстика,
опционально MIDI IN, и отправляет MIDI-события через USB MIDI (в перспективе —
через аппаратный UART MIDI DIN).

## Ключевые функциональные блоки

1. Фильтрация нот по тональности (key/scale quantizer) с тремя режимами обработки
   "неправильной" ноты: подъём/опускание до ближайшей ноты в тональности, либо mute.
2. Генератор аккордов (трезвучия, септаккорды, sus, альтерации, slash, quartal/quintal,
   cluster, power chords) с выбором манеры игры (одновременно / со смещением / перебором).
3. Запись/воспроизведение/редактирование нотных паттернов (пошаговое и в реальном
   времени, overdub по умолчанию).
4. ADSR как модель gate-тайминга (без velocity — см. `03-midi-chain.md`).
5. Арпеджиатор (rate, дистанция в полутонах, кол-во шагов, стиль).
6. Транспонирование в полутонах/октавах.
7. Генератор случайного паттерна и случайной ноты, с общим набором параметров
   рандомизации (длина ноты, диапазон нот, плотность/вероятность, форма, velocity-режим).
8. Swing/groove, humanize, triole/квантизация, legato.
9. Управление BPM и размерностью такта.
10. Обработка MIDI IN → MIDI OUT (устройство как MIDI-процессор в разрыв цепи).

## Аппаратная платформа

- **MCU**: Raspberry Pi Pico, RP2040.
- **Прошивка**: Adafruit CircuitPython 10.0.3 (от 2025-10-17).
- **Дисплей**: монохромный OLED SH1106, I2C, 132×64 px.
- **Ввод нот**: 16 нотных кнопок + 6 функциональных (Play, Record, Shift, Rest,
  Octave Down, Octave Up).
- **Кнопки читаются через два каскадных сдвиговых регистра 74HC165** (24 бита ввода).
- **Джойстик**: KY-023 (аналоговый X/Y + кнопка).
- **MIDI**: сейчас — USB MIDI (`usb_midi` + `adafruit_midi`, уже подключено и работает).
  В перспективе — аппаратный UART MIDI (TX для OUT, оптрон для IN — см. `01-hardware.md`).

## Принятые решения по проекту (зафиксировано с заказчиком)

| Вопрос | Решение |
|---|---|
| MIDI-транспорт | USB MIDI сейчас, UART DIN добавится позже |
| MIDI IN | Нужен, но не сейчас (после UART) |
| Velocity | Не используется — только Note On/Off |
| Точность тайминга | Джиттер в несколько мс допустим |
| Ввод точных значений (мс, BPM, rate) | Джойстик; для длинных диапазонов — удержание
  джойстика или Shift + джойстик влево/вправо (крайние значения) |
| Хранение паттернов | Сейчас только ОЗУ, 16 слотов; ПЗУ — будущая доработка |
| BPM-синхронизация | Пока только внутренний генератор; внешняя MIDI Clock — позже |
| Многодорожечность | Один активный паттерн одновременно (без многодорожечности) |
| Порядок обработки ноты | Тональность → Аккорд → Арпеджио → тайминг-эффекты → Gate/ADSR |
| Аккорд + тональность | Фильтруется вся структура аккорда целиком (не по одной ноте) |
| Радиальный селектор | Общий виджет для Scale/CType/AStyle/Strum: 8 секторов по 45°,
  клик джойстика → edit mode, затем выбор направлением |
| Key (быстрое меню) | Линейная ячейка (12 нот), показывает только выбранную ноту
  (без предикта), click-first |
| Scale/CType/AStyle | В QUICK — радиальные с зоной 0 = **Off**; выбор значения включает блок автоматически. В DETAIL/MAIN — полные списки (без радиуса), Off — первый вариант |
| Strum (быстрое меню) | Радиальная ячейка на строке Chord: Off + 7 значений задержки
  (5–35 мс); voicing редактируется в DETAIL |
| Управление Key/Scale/CType/AStyle | QUICK: через клик джойстика (вход/выход edit mode) + радиальные зоны. DETAIL/MAIN: влево/вправо сразу, без клика |
| Клик-цикл ячеек | QUICK: клик → edit mode, повторный клик применяет. Сброс — Rest+клик (все меню) и двойной клик (~350 мс) в DETAIL/MAIN |
| Приоритет длины ноты в рандоме vs ADSR | У рандома приоритет, ADSR — эффект поверх |
| Арпеджиатор | Доступен в режимах MIDI-клавиатура и MIDI-фильтр |
| Аппаратный баг 74HC165 D4–D7 | Оставить как есть (физическое расположение кнопок настроено) |
| Раскладка нота→цифра | 1-я клавиша = 0, ..., 10-я = 9 |
| Play/Rec в Animation Mode | Не блокируют транспорт |
| Переключение слота при play/rec | Не останавливать воспроизведение |
| Tie vs Legato | Legato в приоритете; повторная та же нота — воспроизводить |
| Расширенные аккорды | В Full Menu (полный список) |
| Акселерация авто-повтора | Ступенчатая: 350ms→150→80→40→25ms |

## Известный аппаратный баг в текущем коде

На втором 74HC165 (диапазон D4–D7 по битовой карте) перепутаны провода: кнопка №13
физически подключена к линии D7 вместо D4. **Решение (30.07.2026):** оставить как
есть — текущее подключение работает, физическое расположение кнопок настроено
под конкретную плату. Программный remap не вносить (см. `01-hardware.md`).

## Статус проекта

Проект реализован до Этапа 6 включительно. Все модули написаны, скомпилированы
и протестированы (на хосте, без железа). Файловая структура:

- `hardware.py` — чтение 74HC165 и KY-023
- `display.py` — инициализация SH1106
- `midi.py` — USB MIDI init
- `state.py` — фабрики Pattern/Step/Slot, 16 слотов в ОЗУ, runtime-состояние
- `state_manager.py` — StateManager (паттерны, транспорт, стек меню)
- `key_filter.py` — 15 ладов (вкл. chromatic), snap_up/down/mute
- `chord_builder.py` — 25 типов аккордов, voicing, secondary_filter
- `arpeggiator.py` — 7 стилей, range
- `timing_effects.py` — swing, humanize, quantize, legato
- `gate_adsr.py` — attack/release gate-модель
- `midi_chain.py` — оркестратор конвейера; `live=True` для живого ввода (без тайминга)
- `sequencer.py` — BPM-таймер, play/stop, note scheduling
- `menu.py` — MenuEngine (QUICK/DETAIL/MAIN/ANIM), радиальный селектор (только QUICK), двухуровневое QUICK-меню (группы Key/Chord/Arp/ADSR + DETAIL)
- `renderer.py` — рендер меню на SH1106
- `mode_engine.py` — конечный автомат 5 режимов: midi_keyboard, pattern, random_pattern,
  random_note, midi_filter
- `code.py` — главный цикл, интеграция всего

### Что не реализовано (сознательно отложено)
- UART MIDI DIN (OUT и IN)
- MIDI Clock sync
- Сохранение на flash/ПЗУ
- Velocity-чувствительный ввод
- Энкодер
- CC-выход / полноценная ADSR-огибающая

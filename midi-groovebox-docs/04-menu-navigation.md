# Навигация меню и режимы экрана

## Разновидности экрана

1. **QUICK** — панель быстрых параметров (Level 1): строки-группы
   (Key/CHD/Arp/RAN*/TIM/ADR/ALL*) с ячейками. Имена строк — максимум 3 символа
   (левая колонка 18 px), поэтому колонки ячеек сдвинуты влево и длинный
   диапазон `F#2:D#4` помещается. Отдельных ячеек `PRM`
   нет: третья ячейка строки показывает конкретный параметр (Snap/Voic/Rate/BPM),
   а клик по **имени строки** (левая колонка) открывает DETAIL. В статус-баре
   выводится текущий режим (`KB` / `RND` / `PTRN`) — клик по заголовку циклит
   режимы (см. «Режим KB/RND/PTRN» ниже). *RAN и ALL видны только в случайных
   режимах; клик по имени **ALL** открывает FULL-меню.
2. **DETAIL** (`<...` — бэк-ссылка) — подменю строки (Level 2): детальные
   параметры группы с полными списками вариантов.
3. **MAIN** (`Main |`) — полное меню: дерево всех параметров устройства.
4. **EDIT** (`Pattern Editor`) — редактор паттерна: мини-карта высот + детальный
   ряд шага; запись с клавиатуры/RND по кнопке Rec (см. «Pattern Editor» в
   `05-input-mapping.md`).
5. **ANIM** (`Anim |`) — декоративный режим (скринсейвер), не редактируется.
   В цикле ручного переключения **не участвует**: запускается автоматически по
   простою (Idle Anim) или вручную из System → **Anim**; любой ввод
   возвращает на экран, с которого анимация была запущена.

DETAIL и MAIN используют общую модель «список параметров» (MenuItem). Радиальный
селектор — **только в QUICK**; в DETAIL/MAIN — только регулярный выбор
варианта влево/вправо.

Переключение между интерактивными экранами происходит на верхнем уровне
навигации: **long-press джойстика на корне** текущего экрана (Quick ↔ FULL ↔ EDIT).

## Управление

| Действие | Эффект |
|---|---|
| Короткий клик джойстика | Войти в выбранный параметр / подтвердить выбор / вход в edit-mode ячейки |
| Клик по имени строки QUICK | Открыть DETAIL этой строки (фокус на имени строки — левая колонка, инвертируется) |
| Короткий наклон джойстика влево/вправо | Изменить значение параметра на ±1 шаг (в DETAIL/MAIN — сразу) |
| Удержание джойстика (long-press), стек не пуст | `pop()` — подняться на уровень выше |
| Удержание джойстика (long-press), стек пуст (корень) | Цикл экранов Quick ↔ FULL ↔ EDIT (анимация в цикле не участвует) |
| Rest + клик джойстика | Сброс значения к снимку (в любом меню) |
| Двойной клик (~double_ms, 300 мс) | Сброс в DETAIL/MAIN (доп. к Rest+клик) |
| Shift + наклон | Прыжок к крайнему значению (min/max) |
| Удержание джойстика в направлении | Авто-повтор с ускорением: ~220 мс → 150 → 110 → 60 мс, на 3-м уровне по 3 шага за тик (`app_loop.cpp`) |

Тайминги кликов настраиваются: System → Debounce / Click 2x / Click Lng
(см. `03-data-structures.md`, ClickSettings) и сохраняются во flash.

## Стек навигации

`MenuEngine` держит стек кадров (`stack_`, глубина до 5). Каждый кадр — либо
набор строк QUICK (`is_rows`), либо список `MenuItem` (DETAIL/MAIN). `rebuild()`
полностью перестраивает содержимое при смене режима/паттерна/test.

## Радиальный селектор (аккорды/арпеджио/лад/струм)

Когда пользователь входит в edit mode радиальной ячейки QUICK (Scale, CType,
AStyle, Strum), джойстик работает как радиальный селектор из **8 секторов по
направлению** (см. `menu_items.cpp` — `direction_to_zone()`):

| Zone | Направление | Scale | CType | AStyle | Strum |
|---|---|---|---|---|---|---|
| 0 | Вверх | **Off** | **Off** | **Off** | **Off** |
| 1 | Вверх-вправо | Major | Maj | Up | 10 мс |
| 2 | Вправо | Minor | Min | Down | 20 |
| 3 | Вниз-вправо | Dorian | Maj7 | Up-Down | 30 |
| 4 | Вниз | Phrygian | Min7 | Down-Up | 40 |
| 5 | Вниз-влево | Lydian | Dom7 | As Played | 50 |
| 6 | Влево | Mixolydian | Sus4 | Random | 75 |
| 7 | Вверх-влево | Blues | Power | Converge/Diverge | 100 |

Зона 0 (вверх) в Scale/CType/AStyle = **Off** (блок выключен). Выбор Scale≠Off
автоматически включает Key Filter; CType≠Off включает Chord; AStyle≠Off включает
Arp (отдельных свитчей в QUICK нет — в DETAIL/MAIN есть).
Strum-зоны теперь идут с шагом 10 мс до 100 мс (раньше до 35 мс, шаг 5).

## QUICK — главный экран (реально построенные строки, `build_quick_rows`)

Строки строятся по активному режиму:

| Строка | Ячейки | Примечание |
|---|---|---|
| **Key** | Linear `Key` (12 нот) + Radial `Scale` + Linear `Snap` | Snap — Up/Dn/Mute; клик по имени строки → DETAIL |
| **CHD** (только KB/RND/MidiFilter) | Radial `Type` + Radial `Strum` + Linear `Voic` | Voic — Blk/Strm/Roll; клик по имени → DETAIL |
| **Arp** (только KB/MidiFilter) | Radial `Style` + Toggle `Latch` + Linear `Rate` | Rate — 1/64..1/1 (Note) или 10–2000 мс (Free, label_fn) |
| **RAN** (RND/PTRN) | Range `PITCH` (мин-макс нота, через двоеточие: `C1:B1`) + Range `LEN` (длины, дефолт `8` — фикс. 1/8) + Linear `REP` (0..90 %, шаг 10) | обе Range-ячейки: «от–до» 2D-управление; вверх/вниз расширяют/сужают диапазон (max±1), влево/вправо сдвигают центр, а при min==max перетаскивают закреплённое значение; 7-символьный `F#2:D#4` влезает — колонки сдвинуты под 3-символьные имена строк; полоса span рисуется **только во время редактирования** своей ячейки; REP — шанс повтора якорной ноты (KEY); клик по имени → Randomize DETAIL (Note Range / Len Range / Len Chain / Gate % / Regen) |
| **TIM** (всегда) | Radial `Swing` + Radial `Hum` + Linear `BPM` | BPM 20..300; клик по имени → DETAIL |
| **ADR** (всегда) | Toggle `On` + Linear `Atk` (0–500 мс) + Linear `Dec` (0–500 мс) | гейт-огибающая прямо в QUICK; дефолты: влияние выключено, Attack 0 мс, Decay 500 мс; клик по имени → полный DETAIL (Switch/Atk/Dec/Sus/Rel/Sync) |
| **ALL** (RandomPattern/RND) | Linear `Dens` (0..100 %, шаг 10) + Linear `Shape` (Asc/Desc/Arch/Rnd) + Linear `STEP` (длина паттерна 4/8/16/32/64) | Dens — шанс rest'а в PTRN (в RND зарезервирована); Shape — зарезервирован; клик по имени строки → переход в FULL-меню |

**Режим KB/RND/PTRN вынесен в статус-бар** (первая строка заголовка) и больше **не
является строкой QUICK**. Статус-бар показывает текущий режим (`KB` / `RND` /
`PTRN`) и
сам является отдельной целью навигации: наклон **вверх** с **любой** ячейки
первой строки переводит фокус на заголовок (режим инвертируется), клик
циклит `KB→RND→PTRN→KB`, наклон **вниз** возвращает на строки в прежнюю колонку
(влево/вправо из заголовка — то же со сдвигом). При смене режима QUICK
перестраивается (исчезают/появляются строки).

Над строками QUICK выводится **строка подписей** параметров сфокусированной
строки (например `Style Latch Rate`), всегда набранная **инверсией** (заливка +
белый текст) и привязанная к верху списка, чтобы пояснения не пропадали при
переходе курсора в нижние строки.

**Фокус строки QUICK**: левая колонка — имя строки (инвертируется при фокусе).
Клик по нему открывает DETAIL; наклон влево с любой ячейки возвращает на имя
строки.

Клик-цикл ячеек QUICK (кроме чек-боксов): клик → edit mode (ячейка выделяется),
джойстик меняет значение (линейные — влево/вправо, радиальные — зоны), повторный
клик применяет и выходит. В edit-mode при отличии от снимка добавляется маркер.

**DETAIL/MAIN**: значения редактируются **сразу** (без клика); переход на другой
пункт «принимает» значение. Если в edit-mode значение отличается от снапшота —
показывается `!` / `+-`.

## Note Range (2D-контрол, DETAIL/MAIN)

`MenuItemType::NoteRange` (`Randomize → Note Range`) — диапазон MIDI-нот
`min..max` (12..119 = C0..B8), редактируется джойстиком как двумерный контрол:

| Действие | Эффект |
|---|---|
| Короткий клик | Активировать 2D-редактирование (значение обрамляется `[..]`) |
| Клик в активном режиме | Подтвердить и выйти |
| Наклон **вверх** / **вниз** | Изменить только **верхнюю** (макс.) ноту на 1 |
| Наклон **влево** / **вправо** | Сдвинуть центр диапазона на 1 ноту (обе границы, прежняя ширина) |
| Rest + клик / двойной клик | Сброс к последнему принятому диапазону и выход |

Та же логика у QUICK-строки **Rand** (RandomNote): клик по ячейке входит в edit-mode, наклон
вверх/вниз двигает макс. ноту, влево/вправо сдвигает центр; клик по имени строки
открывает полный Randomize DETAIL. Границы подсекаются к
`kNoteRangeMin/Max`. Отрисовка: мин. нота слева и макс. справа (например
`C1-C4`, `midi_note_glyph`/`midi_note_octave`), плюс тонкая горизонтальная полоса
под строкой, пропорциональная span по ширине 128 px (закрашенная 2 px у
сфокусированной строки, 1 px у остальных).

## Статус-бар

Строка статуса (`renderer.cpp`): слева имя/режим экрана (на QUICK — текущий режим
`KB`/`RND` вместо `Quick`; на Full/Anim — `Menu`/`Anim`), затем
пиктограммы Play-треугольник / Rec-точка / **иконка ноты**, далее октава `O2`.
**Круг-метроном** (7×7, 4 сектора) стоит между октавой и числом BPM: пока
проигрывание активно (в т.ч. живой RandomNote-цикл), сектор текущей четверти
залит и **вращается по темпу BPM** (счётчик `runtime.beat`, обновляется
в `AppLoop::update_beat` одну четверть = 60000/bpm мс; при slave-синхре от
тактов хоста). Когда транспорт остановлен — круг полый (только контур).
После BPM — шаг `S7` (в PTRN — индекс текущего события), если влезает в 128 px.
Прогресс-линия под статус-баром не рисуется: пошагового playback пока нет, а
цепочки длительностей PTRN она бы искажала. Значки Play/Rec/ноты крупнее (5–6 px),
чтобы метроном и цифры BPM оставались читаемыми.

## Animation Mode

Не содержит редактируемых параметров и **не входит в цикл ручного
переключения экранов** (long-press на корне переключает только Quick ↔ Full).
Два пути запуска:

1. **Автозапуск** — после бездействия (System → **Idle Anim**, 10 000–120 000 мс,
   шаг 5000) Quick/Full автоматически переходит в Animation
   (`AppLoop::update_idle_screensaver`).
2. **Ручной запуск** — System → **Anim**
   (`action_item`, `AppLoop` «усыновляет» переход: запоминает исходный экран).

В обоих случаях **любой** ввод (нота/джойстик/функциональная кнопка) тут же
возвращает на экран, с которого анимация была запущена
(`screensaver_origin_`). Каждое включение анимации стартует со **случайной
стадии** сцены (`AnimationRenderer::restart(seed)` — пересев звёзд, песка, фазы
дюн и таймера комет; seed из текущего времени), так что картинка при входе всегда
разная. Кнопки Play/Rec не блокируются — транспорт в alpha
ограничен (паттерн-секвенсор не реализован, см. `07-roadmap-open-questions.md`).

# Навигация меню и режимы экрана

## Разновидности экрана (именование согласовано 01.08.2026)

1. **QUICK** (`Quick |`) — панель быстрых параметров (Level 1): строки-группы
   (Key/Chord/Arp/ADSR/Dens/Shape) с ячейками. Ячейка `PRM` и строка без ячеек
   (ADSR) открывают DETAIL.
2. **DETAIL** (`<CHD`, `<ADR` — бэк-ссылка) — подменю из `PRM` (Level 2):
   детальные параметры группы с **полными** списками вариантов.
3. **MAIN** (`Main |`) — полное меню: дерево всех параметров устройства.
4. **ANIM** (`Anim |`) — декоративный режим (скринсейвер), не редактируется.

DETAIL и MAIN используют одинаковую модель «список параметров» (items). Радиальный
селектор — **только в QUICK** (быстрая смена); в DETAIL/MAIN — только регулярный
выбор варианта влево/вправо.

Переключение между режимами экрана происходит на верхнем уровне навигации
(см. ниже) — не отдельной кнопкой, а через логику "зажатие джойстика на корневом
уровне".

## Стек навигации (menu_stack)

```
State: {
    screen_mode: "quick" | "full" | "animation",
    menu_stack: [],   # список уровней вложенности, [] = корень текущего screen_mode
}
```

### Управление

| Действие | Эффект |
|---|---|
| Короткий клик джойстика | Войти в выбранный параметр / подтвердить выбор |
| Короткий тап джойстика влево/вправо | Изменить значение параметра на ±1 шаг |
| Shift + тап влево/вправо | Прыжок к крайнему значению (min/max) параметра |
| Удержание джойстика (long-press), `menu_stack` не пуст | `pop()` — подняться на уровень выше |
| Удержание джойстика (long-press), `menu_stack` пуст (корень) | Переключить `screen_mode` по кругу: Quick → Full → Animation → Quick |

Тайминг удержания для long-press — рекомендуется 500–700 мс (стандартное значение
для физических контроллеров, не путается с обычным кликом).

### Псевдокод

```python
def on_joystick_button_release(hold_duration_ms):
    if hold_duration_ms >= LONG_PRESS_MS:
        if state.menu_stack:
            state.menu_stack.pop()
        else:
            state.screen_mode = next_screen_mode(state.screen_mode)
    else:
        enter_or_confirm_current_item()

def on_joystick_tilt(direction, shift_held):
    if direction in ("LEFT", "RIGHT"):
        if shift_held:
            jump_to_extreme(direction)
        else:
            adjust_value(direction, step=1)
```

## Особый случай: радиальный селектор (аккорды/арпеджио)

Когда пользователь находится **внутри параметра типа аккорда или стиля арпеджио**,
джойстик работает не как "влево/вправо на ±1", а как радиальный селектор из 8
секторов по углу вектора (X,Y) — см. `05-input-mapping.md`. Долгое зажатие в этом
режиме всё равно поднимает на уровень выше (выход из выбора аккорда/арпеджио
обратно в меню параметров), логика `menu_stack.pop()` не меняется — просто
интерпретация коротких движений внутри параметра иная (угол, а не бинарное
влево/вправо).

## Содержимое Quick Menu vs Full Menu

**QUICK** — двухуровневый: на главном экране строки-группы, разбитые на
ячейки (cells). Каждая ячейка — редактируемое значение или вход в DETAIL.

### QUICK — главный экран (модель ячеек, зафиксировано 01.08.2026)

Строки-группы (отображаются только относящиеся к активному режиму). Ячейки
показаны в порядке слева направо; `PRM` — ячейка входа в DETAIL:

| Строка | Ячейки на QUICK | Параметры внутри (DETAIL) |
|---|---|---|
| **Key** | `C Off PRM` (по умолчанию тональность **Off**, 02.08.2026) | Key (12 нот), Scale (полные 15), Snap |
| **Chord** | `Maj 10 PRM` | CType (полные 26), CVoic, Strum Delay |
| **Arp** | `Off Off PRM` / `Up On PRM` — AStyle, **Latch** (линейная ячейка Off/On, 02.08.2026) | AStyle (полные 8), Latch, RateMode, Rate, ARange, ASteps |
| **ADSR** | `On` / `Off` (информативно, без ячеек) | Switch, Atk, Dec, Sus, Rel, Sync |
| **Dens** | `50` | (клик-цикл, без PRM) |
| **Shape** | `Asc` | (клик-цикл, без PRM) |

По режимам: Key+ADSR — всегда; Chord — keyboard/random_note/midi_filter;
Arp — keyboard/midi_filter; Dens+Shape — random_pattern/random_note.

Заголовок: `Quick | P.R 120 s0`, `Main | ...`, `Anim | ...` — полным словом.

**Key** — линейная ячейка на 12 нот, показывает только выбранную ноту (без
предикта соседних). **Strum** — радиальная ячейка на строке Chord (зоны
Off/5/10/15/20/25/30/35 мс); voicing редактируется только в DETAIL.

В DETAIL списки **полные** (полноценность вариаций): Scale — 14 ладов + Off,
CType — 25 типов + Off, AStyle — 7 стилей + Off. В QUICK те же параметры — только
радиальные быстрые наборы из 8 зон.

### Навигация и клик-цикл (зафиксировано 01.08.2026)

| Действие | QUICK (Level 1) | DETAIL / MAIN (списки) |
|---|---|---|
| UP/DOWN | переход между строками | переход между пунктами |
| LEFT/RIGHT (навигация) | переключение ячеек внутри строки | — (только редактирование) |
| LEFT/RIGHT | — | изменение значения пункта **сразу** (live); переход на другой пункт = принято |
| Клик (short) на ячейке значения | вход в edit mode ячейки | — (клик только для разделов/действий) |
| Клик на ячейке `PRM` / строке без ячеек (ADSR) | вход в DETAIL | — |
| Клик на раздел (MAIN) / действие | — | вход в раздел / запуск действия |
| В edit mode QUICK: LEFT/RIGHT (linear) или наклон (radial) | изменение значения | — |
| В edit mode QUICK: повторный клик | применить значение и выйти из edit | — |
| Rest + кнопка джойстика | сброс к значению на момент входа в edit | сброс пункта к снимку на момент фокусировки |
| Двойной клик (окно ~350 мс) | — | сброс пункта к снимку (доп. к Rest+клик) |
| Long-press | возврат на уровень выше (из DETAIL); на корне — смена экрана QUICK→MAIN→ANIM | возврат на уровень выше; на корне — смена экрана |

**QUICK: клик-цикл для всех ячеек, кроме PRM.** Клик → edit mode (ячейка в
квадратных скобках `[ ... ]`), джойстик меняет значение (линейные ячейки Key/Dens/
Shape — влево/вправо; радиальные Scale/CType/AStyle/Strum — зоны), повторный клик
применяет и выходит. Радиальные ячейки QUICK — для быстрой смены.

**DETAIL/MAIN: значения редактируются сразу (без клика).** LEFT/RIGHT меняет
вариант/число на ±1; переход на другой пункт автоматически «принимает» значение.
**Rest + клик** (в любом меню) или **двойной клик** (дополнительно в DETAIL/MAIN)
сбрасывают пункт к снимку на момент его фокусировки («значение на момент прихода»).

### Рендер строк Quick (текстовые маркеры, 01.08.2026)

Подчёркивание/инверсия заливкой убраны (нагрузка на устройство, криво на
SH1106). Вместо этого:

- название строки — **по левому краю**, сокращения: `Chord` → `CHD`, `ADSR` → `ADR`;
- фокусная ячейка — в квадратных скобках: `[C]`, `[Off]`, `[PRM]`;
- если в edit mode значение отличается от снимка на момент входа — добавляется
  `!`: `[C#]!`; `!` исчезает при подтверждении, отмене (long-press) или сбросе;
- ячейка `| Param` переименована в `PRM`;
- значок `>` в строках Quick убран (экономия места); в Full/подменю остаётся;
- колонки выровнены по сетке; второй столбец сдвинут левее (зазор меньше), чтобы
  освободить место под `!`;
- в подменю у изменённых с момента входа значений показывается `+-`.

**Радиальные ячейки QUICK (Scale, CType, AStyle, Strum) требуют клика:** вход в
edit mode по нажатию джойстика, выход повторным нажатием. В edit mode движение
джойстика в любом направлении выбирает зону. Линейные ячейки (Key, Dens, Shape) —
тоже клик-цикл: клик → влево/вправо меняет значение → клик. Без клика LEFT/RIGHT
в QUICK только перемещает фокус ячейки (занято навигацией по экрану). В DETAIL/
MAIN радиального управления нет — все пункты (option/slider/toggle) редактируются
влево/вправо сразу, без клика.

Радиальные зоны (Scale/CType/AStyle): зона 0 (вверх) = **Off** (соответствующий
блок выключен), зоны 1–7 = значения. Выбор Scale≠Off автоматически включает
Key Filter; CType≠Off включает Chord; AStyle≠Off включает Arp — отдельных
свитчей в QUICK нет (в DETAIL/MAIN есть Off как первый вариант полного списка).

**MAIN** — древовидная структура всех параметров устройства. Навигация:
джойстик влево/вправо для изменения значения пункта (сразу), клик для входа
в раздел, long-press для возврата на уровень выше. В подменю/MAIN текущий
пункт помечается `>` (в QUICK убран ради экономии места), первая строка —
возврат `<ИмяРодителя`.

## Animation Mode

Не содержит редактируемых параметров. Управление:
- длительное зажатие джойстика — выход по кругу (Quick → Full → Animation → Quick);
- **Play/Rec не блокируются** — паттерн продолжает играть и писаться "под" анимацией
  (решение зафиксировано, см. `07-roadmap-open-questions.md`).
